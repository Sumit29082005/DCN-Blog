1. What is DCN?

Data Communication & Networking (DCN) refers to the process of sending and receiving data between two or more devices through a transmission medium. It includes networking devices, transmission media, protocols, and technologies that enable communication.

2. Important Components of DCN

  • Transmission Media – Fiber optic, copper cable, wireless
  • Switches & Routers
  • Protocols – TCP/IP, UDP, HTTP, FTP
  • Network Topologies – Bus, Star, Ring, Mesh, Hybrid
  • Network Devices – Hub, Switch, Router, Modem, Access Point

3. Types of Computer Networks

  • LAN: Small area like home, office.
  • MAN: Covers a city.
  • WAN: Covers countries.
  • PAN: Bluetooth, Hotspot.
  • WLAN: WiFi networks.

4. Types of Transmission Media

  • Guided: Twisted pair, Coaxial, Fiber optic
  • Unguided: Radio waves, Infrared, Satellite

5. Advantages of DCN

  • Fast data sharing
  • Reduced cost by shared resources
  • Improves communication and teamwork
  • Easy file sharing and backup
  • Enables cloud and online services

6. Disadvantages of DCN

  • High installation and maintenance cost
  • Security risks
  • Server failure affects network
  • Requires trained professionals

7. Why DCN is Important?

DCN is the backbone of modern life. Online banking, WhatsApp, YouTube, business networks, e-commerce, cloud systems, and almost everything depends on data communication.

8. OSI Model (7 Layers)

The OSI model standardizes communication into 7 layers:

  • ❶ Physical Layer
  • ❷ Data Link Layer
  • ❸ Network Layer
  • ❹ Transport Layer
  • ❺ Session Layer
  • ❻ Presentation Layer
  • ❼ Application Layer

9. TCP/IP Model (4 Layers)

  • Application Layer
  • Transport Layer
  • Internet Layer
  • Network Access Layer

10. Network Security

To protect networks, these methods are used:

  • Firewalls
  • Antivirus
  • Encryption
  • VPN (Virtual Private Network)
  • Authentication & Passwords
